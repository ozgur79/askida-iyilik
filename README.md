# Askıda İyilik

Okul içi "Askıda İyilik" hareketinin tanıtım sayfası: okulun sorunlarını herkes dile getirir, sorun sorumlusuna ya da bir gönüllüye gider (Harezmi Eğitim Modeli projesi, 2026–2027).

Bu repo yalnız yayın kopyasıdır; kaynak, projenin ana deposundaki `site/` klasörüdür.
Sayfa tek bir HTML dosyasıdır, dış kaynak (font, analitik, CDN) kullanmaz ve ziyaretçiden veri toplamaz.
